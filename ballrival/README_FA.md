# Ball Rival v2

نسخه مستقل گوی‌های شناور برای گوشی و تبلت. طراحی event-driven است؛ انیمیشن دائمی 60FPS ندارد. هر گوی timer مستقل دارد، بعد از 1 تا 8 ثانیه به نقطه دیگری می‌پرد، لمس گوی آن را با fade حدود 150ms حذف می‌کند، و اندازه/تعداد/شفافیت/زمان قابل تنظیم‌اند.

برای تبلت safe-area و تغییر orientation رعایت می‌شود و Tablet Boost به‌صورت اختیاری اندازه‌ها را کمی بزرگ‌تر می‌کند.

اتصال به Eila اختیاری است. فقط رویدادهای سبک مثل tap/pattern/pause/resume/stop ارسال می‌شوند؛ این رویدادها به‌تنهایی اثبات مطالعه نیستند.
